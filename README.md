# Cursed Hands

A 3D card game game developed in Unity as an academic project. Features include the use of design patterns and custom level design.

## Features

- Implemented design patterns such as:
  - Singleton
  - Observer
  - Factory - Object pool
  - MVC
- Custom level design

## Tech Stack

- Unity (version 2022.3.5f1)
- C#
