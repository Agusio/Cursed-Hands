# Cursed Hands

A 3D card game game developed in Unity as an academic project. Features include the use of design patterns and custom level design.

## Features

- Implemented design patterns such as:
  - Singleton
  - Observer
  - Factory - Object pool
  - MVC
- Custom level design

## How to Run

1. Clone the repository:
    ```
    git clone https://github.com/agusio/Cursed-Hands.git
    ```
2. Open the project in Unity (specify Unity version).
3. Run the scene:
    ```
    Assets/Scenes/MainMenu.unity
    ```

## Tech Stack

- Unity (version 2022.3.5f1)
- C#
